# Hi, I'm Riley

Welcome to my GitHub! I build personal projects and experiments focused on my operating system, Gaia, and programming language, HolyD. I also dabble in game development, modding, and web technology.

## Notable Projects

- **[Gaia](https://github.com/CodeByRiley/Gaia)** *(Formerly TOS)* <br>
  *C, Assembly · x86_64 operating system*  
  An experimental x86_64 operating system built from scratch. It features a preemptive kernel with SMP support, musl-backed POSIX compatibility, a graphical desktop environment with window management, and ports such as DOOM.

- **[HolyD](https://github.com/CodeByRiley/HolyD)**  
  *C · Programming language and virtual machine*  
  A HolyC-inspired scripting language with a D-style influence. It includes a lightweight bytecode VM, a C transpiler, and cross-platform FFI support for windowing, 2D graphics, input, and networking on both TOS and Windows.

- **[My Website](https://codebyriley.com/)**  
  *Astro · Portfolio and blog*  
  My personal website, built with Astro. It includes information about my projects, technical interests, and occasional blog posts.

- **[CodeByRiley](https://github.com/CodeByRiley/CodeByRiley)**  
  *Configuration · GitHub profile*
